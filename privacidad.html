Política de privacidad

Vigente desde el 1 de octubre de 2026. Aplica a las aplicaciones internas "Clasp Run Scripts" y "Workspace CLI" descritas en la página principal.

Quién las usa

Las usa únicamente su titular, Adolfo Andrés Burkart Medina, sobre su propia cuenta de Google. No se ofrecen a terceros.

Qué datos se usan

  • Gmail: remitente, destinatarios, asunto, cuerpo y adjuntos de los correos del titular, para etiquetarlos y archivarlos.

Para qué se usan

Solo para organizar el trabajo del titular. Los datos no se venden, no se usan con fines publicitarios y no se comparten con terceros, salvo lo indicado en el punto siguiente.

Servicios externos

Para clasificar a qué proyecto pertenece un correo, parte de su texto puede enviarse a la API de Gemini de Google. No se envía a ningún otro servicio.

Uso limitado

El uso de la información recibida de las API de Google se ajusta a la Política de datos del usuario de los servicios de API de Google, incluidos los requisitos de uso limitado.

Conservación y eliminación

Lo archivado queda en el Google Drive del titular. El titular puede revocar el acceso en cualquier momento desde myaccount.google.com/permissions.
